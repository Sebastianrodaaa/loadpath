# Artwork

The path mark is an original geometric drawing: two source paths converge on one evidence node.
`scripts/banner.py` renders the mark and pixel blackletter wordmark on black, with monospace captions.

UnifrakturMaguntia by j. 'mach' wust is distributed under the SIL Open Font License 1.1; see `OFL.txt`.
The bundled font comes from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/unifrakturmaguntia).
The banner's typography and monochrome treatment follow [mcp-audit](https://github.com/Sebastianrodaaa/mcp-audit).
