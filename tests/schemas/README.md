# SARIF schema

`sarif-2.1.0.json` is the official SARIF 2.1.0 JSON schema retrieved from
https://json.schemastore.org/sarif-2.1.0.json for offline output validation.
Upstream specification: https://docs.oasis-open.org/sarif/sarif/v2.1.0/ .
